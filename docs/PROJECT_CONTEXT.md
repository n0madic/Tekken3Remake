# PROJECT_CONTEXT — Улучшенная PC-версия Tekken 3

## Что это

Проект улучшенной PC-версии Tekken 3 на основе существующего ремейка:

- **Основа (единственная):** https://github.com/n0madic/Tekken3Remake
- **Технология:** Godot 4.7 (standard, не .NET), GDScript со строгой типизацией
- **Лицензия кода ремейка:** PolyForm Noncommercial 1.0.0
- **Полное ТЗ:** `docs\readme.md` (исполняется без отступлений)

## Константные ограничения (из ТЗ)

- Использовать **только** n0madic/Tekken3Remake; никаких альтернативных проектов, форков, рекомпиляторов (Tekken3Recompiled, Tek3Ex и др. запрещены).
- Не переносить код из других реализаций Tekken 3.
- Не создавать собственные аналоги уже реализованных в ремейке игровых систем.
- Максимально сохранять оригинальные игровые ресурсы.
- Версия диска: **USA SLUS-00402**, эталон SHA256 exe:
  `fbda8b68e5799dbef4af39a161783bc670c15b0aa0e87dce65e210717da19b8c` — **подтверждён** (см. RESEARCH.md).
- НЕ использовать японский образ диска и материалы старого RE-проекта (JP SLPS-91202) — они выведены из оборота.
- Эмулятор не является конечной платформой (DuckStation и пр. — только вспомогательные инструменты, не цель).
- **Ассеты Namco не публиковать**: собранные билды и `remake/imported/` — только для владельца диска.

## Роли

- **OpenCode (агент):** разработка, статический анализ, документация, код.
- **Пользователь:** сам тестирует, запускает игру, проверяет сборки.

## Правила работы

- Строгая экономия токенов: без запуска игры/тестов/длинных диагностик, только статический анализ по задаче.
- После каждой задачи — краткий отчёт и остановка (ждать пользователя).
- Документация проекта — на русском; конвенции кода — по правилам репозитория ремейка (комментарии/доки в коде — на английском, как в оригинальном репо).
- Держать актуальными: NEXT_TASK.md, CHANGELOG.md, DECISIONS.md.
