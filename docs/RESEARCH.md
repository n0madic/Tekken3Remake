## 2. Что такое Tekken3Remake

Два связанных проекта в одном репо:
1. **Research** (`docs/research/`, 43 дока) — каждый формат данных и вся игровая логика PSX-версии; `tools/research/` — проверенные Python-порты процедур игры, доказанные в CPU-харнессе против оригинального кода.
2. **Remake** (`remake/`, 743 файла) — Godot 4.7, план в `docs/remake-plan.md` (милистоуны M0–M6, судя по датам в тексте — план доведён минимум до M5: меню, Theater, локализация, сеттингс; issue #35 закрыт 2026-11-10 → репо активно развивается).

Геймплей воспроизводится **точный до кадра** против оригинала (golden traces); графика модернизируется (тени, bloom, сглаженные текстуры, любой аспект, высокие FPS). Поддержка Windows/macOS/Linux/Web/Android/iOS. Есть аркадный режим по MAME ROM set (`--arcade`) без диска.

## 3. Требования

- **Python 3** + numpy, pillow, xxhash (конвертер).
- **Godot 4.7 standard** (не .NET-версия) — и для запуска, и для экспорта.
- **FFmpeg** — опционально: кодирует музыку (XA→Ogg Vorbis) и фильмы (STR→Ogg Theora). Без него — fallback WAV (QOA) + JPEG-кадры фильмов.
- **MAME chdman** — только для CHD-образов (у нас cue/bin — не нужно).
- Windows-сборка: `make export-windows-full` (есть пресеты full / nomovies / lite).

## 4. Команды (корневой Makefile, `make help`)

```
make convert CONVERT_ARGS='--image "path/to/cue"'   # диск → remake/imported/
make run              # запуск в Godot
make test-quick       # быстрые тесты
make export-windows-* # экспорт Windows-билдов
GODOT=путь_к_году     # переменная для Godot-бинарника
```

Конвертер (`tools/remake_import/convert.py`):
- сам распознаёт релиз по содержимому (`--image` можно дать cue, lone data track, CHD);
- **USA-диск работает один, без японского** — его exe/овелеи ребейзятся на раскладку Japan Rev.1 через `tools/remake_import/layouts/usa.json`;
- пишет только в `remake/imported/` (git-ignored, никогда не коммитить), идемпотентен, пишет `manifest.json`;
- `--no-music`, `--no-movies` — пропустить самые тяжёлые группы.

## 5. Архитектура remake/ (слои, зависимости вниз)

```
app          стейт-машина, переключение сцен, settings
screens      title/menus/select/VS/results/ranking/Theater (Control-сцены)
presentation fighter/stage/effects/camera views, HUD, audio; читает sim, события
core (sim)   детерминированная симуляция: бойцы, ходы, комбо, раунды, камера, AI, правила
content      типизированные ресурсы, загружаемые из imported/
platform     ввод, вибрация, сейвы, локации ассетов
```

Ключевые механики:
- **Симуляция**: фиксированный шаг 60 Гц, целочисленная/фиксированная арифметика (углы 4096/оборот, матрицы 4.12), никаких engine time/physics/random внутри sim; события (звук, эффекты, вибрация) — через per-frame `SimEvents`; состояние — typed RefCounted-объекты с `copy_from()`/`serialize()` (реплеи, rollback-задел).
- **Презентация** рендерит на частоте дисплея с интерполяцией, никогда не пишет в sim.
- **Ввод**: Godot-акшены → 16-битное состояние пада в том же формате, что у оригинала; хот-плаг, два расклада клавиатуры, вибрация DualShock-скриптами, тач-контролы на мобильных.
- **Аудио**: банки SoundBank (WAV с луп-поинтами), музыка Ogg с луп-флагами, два саундтрека (ARRANGE/ARCADE), до 24 голосов.
- **Баги оригинала**: не влияющие на геймплей не воспроизводятся; влияющие — по умолчанию сохраняются, фиксятся одной опцией «Gameplay fixes» (флаги `rules.fix_*`).
- **Сейвы**: `user://progress.json` в своём формате (контент = PSX-блоку), 2 слота-карты; настройки `user://settings.json`.
- **Тексты**: интерфейс ремейка EN/JA (`app/translations.csv`); игровые тексты — с USA-диска (конвертирован только с USA — тексты английские, выбора японского нет).

## 6. USA-версия (docs/research/code/usa-version.md)

- 763 из 770 функций exe идентичны Japan Rev.1; различия — кодировка move-текстов, титул карты сохранений, раунд-стартовый голос в team battle/survival (Япония играет `0x103B`, USA — нет; в ремейке голос оставлен).
- Овелеи `arcade/force/enbu/result/select` кодово идентичны; различия текстов (BACKSTREETS, +LIFE!, REMIXED, RULES и т.д.).
- `TEKN3\TEKKEN3.BNS;1` и `TEKN3\TEKKEN3.XAS;1` — пути USA-диска (у нас на диске каталог `TEKKEN3/` — совпадает по смыслу).
- Конверсия **только с USA-диска официально поддерживается и протестирована**: «весь тест-сьют и trace-сравнения проходят на конверсии с одного USA-диска».

## 7. Конвенции разработки (CLAUDE.md)

- GDScript **строго типизированный**; предупреждения о нетипизированных объявлениях/unsafe-вызовах = ошибки.
- Логи — через платформенный `Log`, не `print`.
- Верификация: golden traces (`tools/research/export_traces.py`), тесты headless через `tools/remake/run_tests.sh` (`tests/run_tests.gd`, `TestSuite`).
- Имена полей состояния — по документации research (fighter.md), английскими словами, не оффсетами.
- Коммитить только код; `remake/imported/` и `remake/.godot/` — игнор.

## 8. Ограничения / риски для нашего проекта

- **PolyForm Noncommercial 1.0.0** — код ремейка некоммерческий; сборки с данными Namco публиковать нельзя.
- Godot 4.7 — обязательная версия (minor-upgrade — отдельная задача).
- Без FFmpeg — музыка WAV (крупнее) и фильмы JPEG-кадрами; лучше поставить FFmpeg с Theora+Vorbis до конвертации.
- Весь геймплей-код уже реализован ремейком (M-милистоуны пройдены): наша работа — установка, конвертация, сборка под Windows и только затем улучшения поверх (не создавая дубликатов реализованных систем — запрет ТЗ).

## 9. План улучшений (раздел ТЗ «улучшения поверх ремейка»)
