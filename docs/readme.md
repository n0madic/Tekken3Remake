# TECHNICAL SPECIFICATION
# Улучшенная PC-версия Tekken 3

## 1. Цель проекта

Создать улучшенную персональную PC-версию оригинальной Tekken 3 на основе существующего проекта:

**Единственная основа разработки:**
https://github.com/n0madic/Tekken3Remake

Мы не создаём игру с нуля, не разрабатываем собственный движок и не переносим игровые системы из других реализаций.

Наша задача — взять существующую реализацию, сохранить оригинальные игровые ресурсы и последовательно улучшить её для комфортной игры на современных компьютерах.

Конечный результат — самостоятельное Windows-приложение, не требующее эмулятора PS1 для игрового процесса.

## 2. Обязательные решения

Эти условия являются постоянными ограничениями проекта.

- Использовать исключительно n0madic/Tekken3Remake.
- Не использовать другие проекты, порты, ремейки, рекомпиляторы и сторонние форки.
- Не переносить код из альтернативных реализаций Tekken 3.
- Не создавать собственные аналоги уже реализованных игровых систем.
- Максимально сохранять оригинальные игровые ресурсы.
- Использовать американскую версию игры.
- Не использовать японский образ и старые наработки, связанные с ним.
- Не использовать эмулятор PS1 в качестве конечной игровой платформы.
- Не переписывать существующий проект без объективной технической необходимости.
- Не подключать платные сервисы, API и инструменты.
- Не расходовать токены на задачи, которые пользователь выполняет самостоятельно.

**Главный принцип: развиваем существующий Tekken3Remake, а не создаём ещё один Tekken 3.**

## 3. Исходные данные

### Игровой образ

Используется американский релиз:

- Идентификатор: SLUS-00402.
- Образ уже скачан пользователем.
- Расположение: папка `iso` в рабочем каталоге.
- Формат: BIN/CUE.

Ожидаемый SHA-256 исполняемого файла:

`fbda8b68e5799dbef4af39a161783bc670c15b0aa0e87dce65e210717da19b8c`

Примечание:
- Контрольная сумма относится к извлечённому EXE, а не к BIN/CUE.
- Оригинальный образ не изменять.
- Не скачивать другие игровые образы.
- Не включать оригинальный образ в публичный репозиторий.

Если проект требует дополнительных ресурсов, использовать только предусмотренные разработчиками способы извлечения из пользовательского образа.

### Лицензирование

Перед началом работы изучить актуальную лицензию репозитория.

Учитывать ограничения PolyForm Noncommercial 1.0.0, если она продолжает действовать.

Проект предназначен для личного некоммерческого использования.

Не публиковать извлечённые игровые данные и сборки с оригинальными защищёнными материалами.
